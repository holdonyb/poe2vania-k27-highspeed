# 流放恶魔城 · k2.7 highspeed

一个结合《流放之路2》构筑要素与恶魔城横版像素动作风格的原型游戏。

- 版本标识：k2.7 highspeed

## 技术栈

- Phaser 3.80
- TypeScript
- Vite 5

## 运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。

## 操作

| 按键 | 功能 |
|------|------|
| ← → / A D | 移动 |
| ↑ / W / Space | 跳跃 |
| Space | 近战攻击 |
| Z | 释放当前技能宝石 |
| 1 2 3 | 切换技能宝石 |
| P | 打开天赋树 |
| I | 打开装备栏 |
| R | 死亡后重新开始 |

## 已实现的 POE2 要素

- **技能宝石系统**：主动宝石 + 辅助宝石组合（火球、冰射、闪电打击）
- **天赋树**：分支式被动加点，分生命/伤害/速度/宝石四系
- **装备词缀**：普通/魔法/稀有/传奇品质，前缀后缀影响属性
- **掉落与升级**：敌人掉落生命球、经验、新宝石、装备

## 已实现的恶魔城要素

- 横版平台跳跃
- 多层平台关卡
- 近战 + 远程技能战斗
- 敌人巡逻与追击 AI
- 像素美术占位资源
